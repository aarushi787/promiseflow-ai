# Pilot acceptance

Choose one company, one plant and a bounded two/three-week planning horizon. Nominate a PPC data owner and a manager responsible for publication. Obtain real resource calendars, operation alternatives, setup/cycle units, material reservation ownership, incoming supply, operator/tool capacities and customer cutoffs.

Start with read-only comparison against the planner's known schedule. Resolve readiness warnings and calibrate discrepancies. Exercise shortage, breakdown, skill absence, held material, critical order and impossible hard deadline cases. Verify every old commitment remains visible and that Sales cannot activate a plan.

Pilot sign-off requires deployment HTTPS/security review, backup-and-restore drill, named-user roles, representative constraint validation, acceptable solve times and review of every unmodeled assumption. Record approvals outside the tool where a formal quality/engineering signature is required.

This release does not ingest actual starts/completions or decrement inventory. Reconcile work manually before advancing a planning epoch. Do not use it for unattended rolling production promises or regulated process-release decisions. Expand only after adding actuals reconciliation and manufacturing-specific constraints with regression tests.
